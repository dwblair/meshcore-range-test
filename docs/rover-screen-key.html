D: direct ping

ShowsMeaning
+12ACK received. SNR (dB) of the house's reply. Higher is better; it stops working below about −7.
xNo ACK. No direct radio link from here, or the reply was lost.
..Sent, waiting for the ACK (up to ~7 s).
!Send failed inside the Rover (rare).
?No contact: the Rover lacks this house's card.
-Not tried since the Rover started.

R: routed ping

ShowsMeaning
0hACK received; the flood reached the house directly.
2hACK received via that many repeater hops.
okACK received; hop count not learned.
xNo ACK in 30 s: not reachable even through the public mesh.
..Sent, waiting for the ACK (up to ~30 s).
wSkipped: this house got a flood <1 min ago (rate limit).
! ? -Send failed / no contact / not tried yet.

Reading a line

D+12 R0hHouse in direct range.
D-6 R0hDirect link, but marginal (near −7).
Dx R3hNo direct link; reachable through 3 repeaters.
Dx RxNot reachable from here at all.

Relay site? If both houses show a number after D in the same round, a repeater here would hear both.

Buttons (PRG)

shortNext screen: main → Send now → Repeat → Send advert.
long(~1 s) On main or Send now: send a round now. Busy = a round is still running (up to ~75 s).
longOn Repeat: toggle repeating (turn on only when parked).
longOn Send advert: let a nearby house learn the Rover's key.

Rounds run every 5 min automatically. Every result is logged with GPS position; upload the log when home.

PRG held while tapping RST enters flashing mode, so don't hold it at power-up. Firmware: examples/range_test (meshcore-range-test).
